多账号配置多代码平台

Lirioing2025/05/08常见问题Git

问题的背景

工作时用的公司邮箱注册的账号，自己平时学习时用的 Github 账号和 Gitee 账号，但是又只有一个电脑，公司账号不能用户 Github，所以需要配置多套秘钥，分别用于代码研究和公司开发使用。

本地账号关联远程github|gitlab|gitee

1、本地创建ssh-key

首先删除本地的.ssh目录

接着创建一个ssh-key，

ssh-keygen -t rsa -C "xx@xx.com"

一直回车执行完上面的命令后，这时会在本地的.ssh目录中创建两个文件 id_rsa 和 id_rsa.pub

2、把id_rsa.pub文件中的内容复制到远程代码平台中，即可正常push和pull操作

Git本地配置多平台账号

上面创建的ssh-key，生成了 id_rsa 和 id_rsa.pub 俩文件，这种情况只能适用于一个账号多个平台，不能用于多个账号。

所以，那我们再创建一个套新的ssh-key，起一个不同的名字，使用不同的邮箱账号

第一步，进入到.ssh目录

cd ~/.ssh

再次执行下面的命令，

ssh-keygen -t rsa -C "xx@xx.com"

按完回车之后，修改密钥的名称，起一个不一样的名称，例如用在github平台，那么名字则为id_rsa_github

现在我们就拥有了两个账号和密钥，一个用于链接公司的代码平台，一个用于github

最后一个问题，怎么知道你用哪个账号提交远程仓库呢

我们还需要编写一个配置文件，当提交公司代码平台是要给你账号A，提交github时，用账号B

在.ssh目录中新建config文件

执行命令： vi config ，按下键盘的 i 键，切换到输入状态。

输入一下代码，

# 第一个账号，平台名称
Host codeup.aliyun.com
HostName codeup.aliyun.com
User xx@xx.com
IdentityFile ~/.ssh/id_rsa

# 第一个账号，平台名称
Host github.com
HostName github.com
User xx@xx.com
IdentityFile ~/.ssh/id_rsa_github

依次按下 esc : wq, 按下回车，保存文件

我们可以顺利的进行多账号多个代码平台的使用
