1. 如何让AI接收你的提问

在使用TRAE AI进行开发时，有效的提问方式是获得准确回应的关键。以下是几种让AI接收并理解你提问的方法：

1.1 明确的问题描述

  • 具体而非模糊：提供具体的问题描述，避免使用过于宽泛的表述
  • 上下文信息：包含足够的上下文，让AI了解问题的背景
  • 目标明确：清楚说明你希望达成的目标或解决的问题

1.2 代码相关问题

  • 提供代码片段：直接粘贴相关代码，确保代码格式正确
  • 指出具体问题：明确说明代码中遇到的问题或期望的改进
  • 环境信息：提供相关的技术栈、框架版本等环境信息

1.3 项目相关问题

  • 项目结构：描述项目的基本结构和相关文件
  • 依赖关系：说明项目的依赖库和版本
  • 具体场景：提供问题出现的具体场景和复现步骤

1.4 提问技巧

  • 分步骤提问：复杂问题可以分多个步骤提问，逐步深入
  • 使用标记：对代码、文件路径等使用适当的标记，提高可读性
  • 明确期望：说明你期望的回答类型（代码示例、解释说明等）

1.5 示例

好的提问示例：

在我的Vue 3项目中，使用axios发送POST请求时遇到了CORS错误。具体代码如下：

import axios from 'axios';

async function submitForm() {
  try {
    const response = await axios.post('https://api.example.com/submit', {
      name: 'John',
      email: 'john@example.com'
    });
    console.log(response.data);
  } catch (error) {
    console.error('Error:', error);
  }
}

我已经在后端设置了CORS头，但仍然收到错误。如何解决这个问题？

不好的提问示例：

我的代码有问题，帮我看看。
